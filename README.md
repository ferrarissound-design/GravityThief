# 重力泥棒 | Gravity Thief

箱から重力をぬすみ、部屋の6方向へ向け直して道を開く、ブラウザ向け3Dパズルゲームです。制限時間や失敗回数はなく、PCとスマートフォンの両方で遊べます。

公開ページ: https://ferrarissound-design.github.io/GravityThief/

## 5つのステージ

1. **はじめの一歩** — 箱を横へ送り、もう一度重力をぬすんで床のスイッチへ落とします。
2. **壁をこえろ** — 天井方向を使い、低い壁を越えます。
3. **重力の曲がり角** — 1つの箱と半透明の壁で、複数方向を順番に組み合わせます。
4. **ふたつの重力** — 2つの箱で2つの保持式スイッチを同時に押します。
5. **重力コア** — ラッチ式スイッチで中間ゲートを開き、2つ目の箱で最終扉を開きます。

クリア画面の「次のステージへ」で進みます。「もう一度遊ぶ」は現在のステージを最初から読み込みます。ステージ5クリア後は、最初から再挑戦するか、ステージ5で自由に遊べます。

## 操作方法

### PC

- `W` `A` `S` `D`: 移動
- `Shift`: ダッシュ
- `Space`: ジャンプ
- マウスドラッグ: カメラ回転
- `E`: 光るリングが付いた箱から重力をぬすむ
- `1`〜`6`: 重力方向を選ぶ
- `R`: 現在のステージをリセット
- `Esc`: 重力選択画面または操作説明を閉じる

### スマートフォン

- 左下スティック: 移動
- 画面右側をドラッグ: カメラ回転
- `JUMP`: ジャンプ
- `STEAL`: 操作できる箱から重力をぬすむ
- 重力選択の6つの大きなボタン: 重力方向を決定
- 右上のリセットボタン: 現在のステージをリセット

タッチ操作中は数字キーの表示を隠します。`STEAL` は対象がないとき灰色になり、操作できるときだけ発光します。

## 酔いにくいカメラ設定

画面右上の歯車ボタンから「酔いにくいモード（Motion Comfort）」とカメラ感度を変更できます。

- スマートフォンではMotion Comfortが初期状態でON、感度は「低い」です。
- PCでもMotion Comfortは初期状態でON、感度は「ふつう」です。
- 感度は「低い」「ふつう」「高い」の3段階です。
- Motion Comfortでは、遠めの固定FOVカメラ、弱いジャンプ追従、滑らかな壁補正、小さな画面中央点を使用します。
- OFFでも画面シェイク、ロール、回転慣性、速度連動ズームは使用しません。
- スマートフォンでは画面右側の空いている部分をドラッグしてカメラを回します。移動スティックや各ボタンの指はカメラ操作に使われません。

設定は `gravityThiefMotionComfort` と `gravityThiefCameraSensitivity` として `localStorage` に保存されます。

## 重力の方向

方向はカメラやロボットの向きではなく、部屋の固定座標が基準です。

- 左の壁: `-X`
- 右の壁: `+X`
- 奥の壁: `-Z`
- 手前の壁: `+Z`
- 床: `-Y`
- 天井: `+Y`

方向ボタンをホバー、フォーカス、または長押しすると、箱の3D矢印と行き先の面が光ります。

## セーブとリセット

`localStorage` に最後に遊んだステージと到達済みの最高ステージを保存します。主なキーは `gravityThiefCurrentStage` と `gravityThiefHighestStage` です。値が壊れている場合はステージ1へ安全に戻ります。

リセットは現在のステージだけに作用し、プレイヤー、箱、重力、スイッチ、扉、ゴール、一時エフェクトを初期状態へ戻します。ステージ番号と到達状況は消しません。

## 開発

Node.js 20.19以上、または22.12以上を使用してください。

```bash
npm install
npm run dev
```

5ステージの読み込み、スイッチ・扉・ゴール規則、物理ボディの破棄を確認するには次を実行します。

```bash
npm run test:stages
npm run test:camera
```

本番ビルドとローカルプレビュー:

```bash
npm run build
npm run preview
```

Viteの `base` は公開先 `/GravityThief/` に合わせてあり、生成物はGitHub Pagesで配信できます。

## 技術構成

- Three.js: 3D表示
- cannon-es: 物理演算
- Vite: 開発サーバーと本番ビルド
- `src/game/stages/stageDefinitions.js`: 5ステージの設定データ
- `src/game/stages/stageLoader.js`: 共通の生成・破棄処理
