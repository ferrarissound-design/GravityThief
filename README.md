# 重力泥棒 Prototype

箱から重力を盗み、6方向から新しい重力を設定して床スイッチまで運ぶ、ブラウザ向け3Dパズルゲームの初期プロトタイプです。スイッチで扉を開き、奥のゴールへ入るとクリアです。

## インストール

Node.js 20.19以降（または22.12以降）を用意し、次を実行します。

```bash
npm install
```

## 起動

```bash
npm run dev
```

表示されたローカルURLをブラウザで開いてください。本番ビルドは `npm run build`、ビルド結果の確認は `npm run preview` です。

## PC操作

- `W` `A` `S` `D`: 移動
- `Shift`: ダッシュ
- `Space`: ジャンプ
- マウスドラッグ: カメラ回転
- `E`: 近くの箱から重力を盗む
- `1`〜`6`: 箱へ設定する重力方向を選ぶ
- `R`: ステージをリセット
- `Esc`: 重力選択・操作説明を閉じる

## タッチ操作

- 左下の仮想スティック: 移動
- 画面右側のドラッグ: カメラ回転
- `JUMP`: ジャンプ
- `STEAL`: 箱から重力を盗む
- 重力を盗んだ後の6方向ボタン: 箱の重力方向を設定
- 右上のリセットボタン: ステージをリセット

## 現在実装されている機能

- Three.jsの基本形状だけで作った部屋、ロボット、箱、スイッチ、扉、ゴール
- cannon-esによる固定タイムステップ物理演算
- プレイヤーの常時下向き重力と、箱ごとの6方向重力・無重力状態
- 箱との距離判定、重力の盗取、6方向への再設定
- 重力方向を示す3D矢印、無重力マーク、変更時の粒子エフェクト
- 箱で押せる床スイッチ、滑らかに開く扉、ゴールとクリア画面
- リセットとステージ外落下時の自動復帰
- PC・タッチ操作、レスポンシブUI
